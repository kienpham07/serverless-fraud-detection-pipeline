## Overview

This commit implements the foundational Infrastructure as Code (IaC) layer using Terraform to provision storage, database, streaming, messaging, and security resources for the serverless fraud detection pipeline. It establishes an S3 raw transaction bucket configured with SSE-AES256, public access blocking, and lifecycle transitions; a DynamoDB `FlaggedTransactions` table with on-demand billing, GSI indexing, and real-time CDC streams; and an encrypted SNS alerting topic with email subscription delivery. Crucially, strictly scoped least-privilege IAM roles and policy documents are defined for both the ingestion and alerting Lambda functions without relying on wildcard permissions.

## Code Changes

### Least-Privilege IAM Execution Roles for Serverless Functions
In `terraform/iam.tf`, fine-grained IAM policy documents ensure each Lambda function can only interact with its required AWS resources without wildcard access:
```hcl
# Ingestion Lambda: Read raw S3 objects, write flagged transactions to DynamoDB
data "aws_iam_policy_document" "ingestion_lambda_policy_doc" {
  statement {
    sid       = "AllowS3RawGetObject"
    effect    = "Allow"
    actions   = ["s3:GetObject"]
    resources = ["${aws_s3_bucket.raw_transactions.arn}/raw/*"]
  }

  statement {
    sid       = "AllowDynamoDBPutItem"
    effect    = "Allow"
    actions   = ["dynamodb:PutItem"]
    resources = [aws_dynamodb_table.flagged_transactions.arn]
  }

  statement {
    sid     = "AllowCloudWatchLogging"
    effect  = "Allow"
    actions = [
      "logs:CreateLogGroup",
      "logs:CreateLogStream",
      "logs:PutLogEvents"
    ]
    resources = [
      "arn:aws:logs:${data.aws_region.current.name}:${data.aws_caller_identity.current.account_id}:log-group:/aws/lambda/*"
    ]
  }
}

# Alerting Lambda: Consume DynamoDB stream shards, publish alerts to SNS
data "aws_iam_policy_document" "alerting_lambda_policy_doc" {
  statement {
    sid     = "AllowDynamoDBStreamProcessing"
    effect  = "Allow"
    actions = [
      "dynamodb:GetRecords",
      "dynamodb:GetShardIterator",
      "dynamodb:DescribeStream",
      "dynamodb:ListStreams"
    ]
    resources = [
      aws_dynamodb_table.flagged_transactions.stream_arn,
      aws_dynamodb_table.flagged_transactions.arn
    ]
  }

  statement {
    sid       = "AllowSNSPublishAlerts"
    effect    = "Allow"
    actions   = ["sns:Publish"]
    resources = [aws_sns_topic.fraud_alerts.arn]
  }
}
```

### DynamoDB Storage with Change Data Capture (CDC) Streams
In `terraform/dynamodb.tf`, the table stores flagged transactions with on-demand scaling, point-in-time recovery, and stream publishing for real-time alerting:
```hcl
resource "aws_dynamodb_table" "flagged_transactions" {
  name             = "FlaggedTransactions"
  billing_mode     = "PAY_PER_REQUEST"
  hash_key         = "transaction_id"
  stream_enabled   = true
  stream_view_type = "NEW_IMAGE"

  attribute {
    name = "transaction_id"
    type = "S"
  }

  attribute {
    name = "account_id"
    type = "S"
  }

  attribute {
    name = "timestamp"
    type = "S"
  }

  global_secondary_index {
    name            = "AccountTimeIndex"
    hash_key        = "account_id"
    range_key       = "timestamp"
    projection_type = "ALL"
  }

  point_in_time_recovery {
    enabled = true
  }

  server_side_encryption {
    enabled = true
  }
}
```

### Encrypted S3 Ingestion Bucket with Lifecycle Transition
In `terraform/s3.tf`, the landing bucket enforces default AES256 server-side encryption, public access blocking, and cost-optimization lifecycle rules:
```hcl
resource "aws_s3_bucket" "raw_transactions" {
  bucket_prefix = "fraud-pipeline-"
  force_destroy = true
}

resource "aws_s3_bucket_server_side_encryption_configuration" "raw_transactions_sse" {
  bucket = aws_s3_bucket.raw_transactions.id

  rule {
    apply_server_side_encryption_by_default {
      sse_algorithm = "AES256"
    }
  }
}

resource "aws_s3_bucket_lifecycle_configuration" "raw_transactions_lifecycle" {
  bucket = aws_s3_bucket.raw_transactions.id

  rule {
    id     = "transition-raw-to-standard-ia"
    status = "Enabled"

    filter {
      prefix = "raw/"
    }

    transition {
      days          = 30
      storage_class = "STANDARD_IA"
    }
  }
}
```

### Encrypted SNS Alerting Topic with Email Subscription
In `terraform/sns.tf`, the notification topic broadcasts alerts to subscribing fraud analysts:
```hcl
resource "aws_sns_topic" "fraud_alerts" {
  name              = "fraud-detection-alerts"
  kms_master_key_id = "alias/aws/sns"
}

resource "aws_sns_topic_subscription" "email_alert" {
  topic_arn = aws_sns_topic.fraud_alerts.arn
  protocol  = "email"
  endpoint  = var.alert_email
}
```
