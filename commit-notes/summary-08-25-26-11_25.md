## Overview

This initial commit establishes the foundational project structure, architectural specification, and machine learning components for the Serverless Fraud Detection Pipeline. It introduces a high-fidelity synthetic transaction data generator, an automated training and evaluation pipeline for a lightweight Random Forest fraud classifier optimized for AWS Lambda execution, and a streaming S3 log replay utility to simulate event-driven transaction ingestion. Additionally, project scaffolding is established across Lambda function directories, Terraform infrastructure modules, and Python dependency configurations.

            amount = float(np.random.uniform(800.0, 4800.0))
        else:
            amount = float(np.random.uniform(0.50, 4.99))

        tx_freq = int(np.random.randint(10, 45))

### Lightweight Random Forest Model Training & Lambda Optimization
In `scripts/train_model.py`, a Random Forest classifier is trained with class weighting and bounded tree depth/estimators to ensure minimal cold-start latency and small memory footprint in AWS Lambda:
```python
def train_fraud_model(
    X_train: pd.DataFrame,
    y_train: pd.Series,
    n_estimators: int = 40,
    max_depth: int = 6,
    random_state: int = 42,
) -> RandomForestClassifier:
    """Train a lightweight Random Forest model with class balancing."""
    logger.info(
        "Training RandomForestClassifier (n_estimators=%d, max_depth=%d, features=%s)...",
        n_estimators,
        max_depth,
        list(X_train.columns),
    )
    start_time = time.perf_counter()

    clf = RandomForestClassifier(
        n_estimators=n_estimators,
        max_depth=max_depth,
        random_state=random_state,
        class_weight="balanced",
        n_jobs=-1,
    )
    clf.fit(X_train, y_train)

    train_duration = time.perf_counter() - start_time
    logger.info("Training completed in %.3f seconds.", train_duration)
    return clf
```

### S3 Event-Driven Log Replay Simulator
In `scripts/replay_logs.py`, batches of synthetic transaction records are formatted into CSV streams and uploaded to AWS S3 at scheduled intervals to trigger real-time ingestion events:

    batch_size: int,

    dry_run: bool = False,
    local_dir: Optional[str] = None,
) -> None:
    """Execute continuous log replay loop."""
    stats = StreamingStats()
    running = True

    def handle_shutdown(signum: int, frame: Any) -> None:

        logger.info("\nReceived termination signal. Gracefully finishing current batch...")
        running = False

    signal.signal(signal.SIGINT, handle_shutdown)
    signal.signal(signal.SIGTERM, handle_shutdown)

    # Replay loop streaming batches to S3
    while running:
