## Overview

This commit implements the asynchronous alerting microservice (`lambda/alerting/handler.py`) and its automated Terraform infrastructure (`terraform/lambda_alerting.tf`). The service consumes real-time Change Data Capture (CDC) events via DynamoDB Streams from the `FlaggedTransactions` table, filters for new `INSERT` events, and deserializes DynamoDB attribute maps into standard Python primitives. It evaluates alert severity levels (`CRITICAL` vs `WARNING`), constructs formatted human-readable notifications alongside structured JSON payloads, and broadcasts real-time security alerts via Amazon SNS with message attributes.

## Code Changes

### DynamoDB Stream Deserialization & Severity Assessment
In `lambda/alerting/handler.py`, raw DynamoDB typed images are unpacked and categorized by transaction value and detection method:
```python
def deserialize_dynamodb_image(image_dict: Dict[str, Any]) -> Dict[str, Any]:
    """Deserialize raw DynamoDB attribute maps into standard Python primitives."""
    if not image_dict:
        return {}
    deserialized: Dict[str, Any] = {}
    for key, val in image_dict.items():
        try:
            deserialized[key] = deserializer.deserialize(val)
        except Exception as exc:
            logger.warning("Failed to deserialize field '%s': %s", key, str(exc))
            deserialized[key] = val
    return deserialized


def determine_alert_level(
    amount: float,
    detection_type: str,
) -> Tuple[str, str]:
    """Determine the severity level and indicator for the fraud alert.

    Alert Level is CRITICAL if amount > $5,000 or if triggered by HYBRID detection.
    Otherwise, Alert Level is WARNING.
    """
    is_critical = (amount > 5000.00) or (detection_type.upper() == "HYBRID")
    if is_critical:
        return ("CRITICAL", "🚨 CRITICAL")
    return ("WARNING", "⚠️ WARNING")
```

### Multi-Format Notification Formatting & SNS Dispatch
In `lambda/alerting/handler.py`, incoming items are rendered into structured email bodies and published to SNS with filterable message attributes:
```python
def build_alert_payloads(record: Dict[str, Any]) -> Tuple[str, str, str]:
    """Build human-readable message, structured JSON payload, and subject line."""
    tx_id = str(record.get("transaction_id", "UNKNOWN"))
    acc_id = str(record.get("account_id", "UNKNOWN"))
    raw_amount = record.get("amount", 0.0)
    amount = float(raw_amount) if isinstance(raw_amount, (Decimal, int, float)) else 0.0
    detection_type = str(record.get("detection_type", "RULE")).upper()

    alert_level, badge = determine_alert_level(amount=amount, detection_type=detection_type)
    subject = f"[{alert_level} FRAUD ALERT] Acc: {acc_id} | ${amount:,.2f} ({detection_type})"

    human_message = f"""============================================================
{badge} FRAUD DETECTION ALERT - IMMEDIATE ACTION REQUIRED
============================================================
Alert ID          : alt_{uuid.uuid4().hex[:12]}
Alert Level       : {alert_level}
Detection Type    : {detection_type}
Status            : {record.get('status', 'PENDING_REVIEW')}
------------------------------------------------------------
TRANSACTION DETAILS:
  Transaction ID  : {tx_id}
  Account ID      : {acc_id}
  Amount          : ${amount:,.2f}
  Timestamp (UTC) : {record.get('timestamp')}
  Risk Score      : {float(record.get('risk_score', 0.0)):.4f}
------------------------------------------------------------
TRIGGERED RULES & REASONS:
  {record.get('flag_reason', 'Anomalous transaction pattern detected')}
============================================================"""

    return (subject, human_message, json.dumps(record, default=to_serializable, indent=2))
```

### Lambda Deployment & DynamoDB Stream Event Source Mapping
In `terraform/lambda_alerting.tf`, the Lambda function is deployed with least-privilege IAM credentials and linked directly to the DynamoDB Stream:
```hcl
resource "aws_lambda_function" "alerting_lambda" {
  function_name    = "${var.project_name}-alerting"
  description      = "Consumes DynamoDB Streams from FlaggedTransactions and broadcasts real-time alerts via SNS"
  filename         = data.archive_file.alerting_lambda_zip.output_path
  source_code_hash = data.archive_file.alerting_lambda_zip.output_base64sha256
  runtime          = "python3.11"
  handler          = "handler.lambda_handler"
  memory_size      = 128
  timeout          = 30
  role             = aws_iam_role.alerting_lambda_role.arn

  environment {
    variables = {
      SNS_TOPIC_ARN   = aws_sns_topic.fraud_alerts.arn
      AWS_REGION_NAME = var.aws_region
    }
  }
}

resource "aws_lambda_event_source_mapping" "dynamodb_stream_trigger" {
  event_source_arn                   = aws_dynamodb_table.flagged_transactions.stream_arn
  function_name                      = aws_lambda_function.alerting_lambda.arn
  starting_position                  = "LATEST"
  batch_size                         = 10
  maximum_batching_window_in_seconds = 5
  bisect_batch_on_function_error     = true
  enabled                            = true
}
```
